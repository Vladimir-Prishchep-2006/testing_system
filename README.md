\# Система онлайн-тестирования и оценки результатов



Курсовая работа по дисциплине «Веб-программирование»: FastAPI, Pydantic, SQLAlchemy (SQLite), Jinja2, JWT.



Магазин тестов: каталог из 30 тестов по 10 предметам, корзина, оформление заказа, личный кабинет.

Покупается право на попытки прохождения: цена указана за одну попытку, количество в корзине это число попыток.

Оплата имитируется: заказ сразу получает статус «оплачен».



\## Запуск



```bash

python -m venv venv

venv\\Scripts\\activate            # Linux/macOS: source venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload

```



\- сайт: http://127.0.0.1:8000/

\- документация API: http://127.0.0.1:8000/docs и http://127.0.0.1:8000/redoc



При первом запуске создаются таблицы, два пользователя и каталог. Если схема таблиц изменилась,

остановите сервер и удалите файл `testing.db`, он создастся заново.



| Логин   | Пароль     | Роль                          |

|---------|------------|-------------------------------|

| admin   | admin123   | администратор (преподаватель) |

| student | student123 | покупатель (студент)          |



Новые пользователи, зарегистрированные через сайт, всегда получают роль студента.



\## Соответствие методичке (п. 3.2)



| Требование                                  | Реализация                                                         |

|---------------------------------------------|--------------------------------------------------------------------|

| Каталог с категориями и пагинацией          | `GET /api/tests`, `GET /api/categories`                            |

| Страница товара                             | `GET /api/tests/{id}`, страница `/tests/{id}`                      |

| Поиск и фильтры: название, категория, цена  | параметры `search`, `category\_id`, `min\_price`, `max\_price`        |

| Сортировка (п. 3.3)                         | параметр `sort`                                                    |

| Регистрация, аутентификация, роли           | `/api/auth/\*`, JWT, роли student и admin                           |

| Корзина: добавить, изменить кол-во, удалить | `/api/cart`, `/api/cart/items`                                     |

| Оформление заказа, история заказов          | `POST /api/orders`, `GET /api/orders/me`                           |

| Админ-маршруты каталога                     | создание, изменение, удаление тестов, вопросов и категорий         |



Специфика темы: таймер, автопроверка, оценка по пятибалльной шкале, статистика по тесту для администратора.



\## Структура



```

app/

├── main.py        # приложение, подключение роутеров, HTML-страницы

├── database.py    # подключение к БД, сессия

├── models.py      # ORM-модели SQLAlchemy

├── schemas.py     # Pydantic-схемы (валидация входа, формат ответа)

├── security.py    # хеширование паролей, JWT, проверка роли

├── grading.py     # проверка вопроса и перевод процента в оценку

├── seed.py        # демо-данные: 30 тестов, 120 вопросов

├── routers/       # auth, catalog, cart, orders, attempts

├── templates/     # Jinja2: base, catalog, test, cart, auth, profile

└── static/        # style.css, app.js

```



Администратор управляет каталогом через Swagger UI (/docs, кнопка Authorize).
